ESP32 烧录与串口工具（Windows 7 SP1 / 32位和64位）

直接双击 ESP32_Flasher_Win7.exe，无需安装 Python 或 pip。
启动时会解压内置运行库，第一次启动请稍等几秒。

1. 安装开发板 USB 串口芯片对应的 Windows 7 驱动。
2. 选择串口、芯片和烧录模式，选择 bin 文件。
3. 按固件说明填写烧录地址，点击“开始烧录”。
4. 在“串口交互”页打开串口，输入内容后按回车发送。

三种模式：单个 bin、经典 ESP32 标准三文件、自定义多文件。
三文件默认地址：bootloader 0x1000、分区表 0x8000、应用 0x100000（1 MB）。
应用地址按本项目要求设置，分区表中的应用分区也须与此地址匹配。
三文件模板不适用于所有 ESP32 系列芯片，地址必须按编译产物确认。

擦除功能：选择串口和芯片，点击“擦除整片 Flash”，确认后执行。
无需选择 bin。会清除固件、分区表和 NVS 等 Flash 数据，无法恢复。
不修改 eFuse；擦除后需重新烧录固件。支持日志和“取消操作”，
取消可能留下部分擦除状态，请重新擦除后烧录。

烧录失败：关闭其他串口软件，降低波特率；必要时按住 BOOT 并短按 EN 后重试。
取消烧录可能留下不完整固件，请重新烧录。

已在当前 Windows 环境检查独立 EXE 的启动、烧录子进程和错误处理，
并使用 Python 3.8.10 x86 通过软件测试。未进行 Win7 实机及 ESP32 实际写入测试。
Win7 必须为 SP1；系统缺少通用 C 运行库等组件时仍可能需要微软系统更新。
